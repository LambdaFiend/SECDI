# SECDI
**SECD** **I**nterpreter.

## Introducing

An implementation of a SECD interpreter as per Lawrence Paulson.

## Running the program

Haskell and Cabal should both be installed.

```cabal build```

```cabal run```

Type ```:?```, ```:h``` or ```:help``` for help within the program.
